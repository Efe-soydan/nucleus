# nucleus
Nuclear calculation tool for engineering students — binding energy, isotope table, molar mass (Python)

## Özellikler
- Nükleon bağlanma enerjisi (BE/A) hesaplama
- 118 element için izotop tablosu
- Atomik kütle, yoğunluk ve molar kütle hesapları
- Bağlanma enerjisi karşılaştırmaları
